# 🏥 AWS Health Dashboard Overview

## 🧩 Definition

The **AWS Health Dashboard** is a tool designed to help users **monitor and manage AWS service health and issues**.

It is divided into two main sections:

- 🌎 **Events affecting all users**
- 👤 **Events specific to an account's resources**

---

## 🌎 Service Health

The **Service Health** section provides information about:

- 🔴 Open issues across the AWS platform
- 🕒 Recent issues
- 📜 Historical issues

The historical view can help users:

- 🔍 Understand past service disruptions
- 🏗️ Plan for high availability

---

## 👤 Your Account Health

The **Your Account Health** section correlates global AWS issues with:

- ☁️ AWS resources being used
- ⚙️ AWS services being used

This provides a more targeted understanding of how AWS issues may impact:

- 🏢 Your account
- 📊 Your business

---

## 🏢 AWS Organizations

The AWS Health Dashboard is particularly beneficial for users with:

- 🏢 **AWS Organizations**

This helps provide visibility into AWS health events that may affect the organization's environment.

---

## 🔗 Health API

A **business or enterprise-level support plan** provides access to the **Health API**.

The Health API can be used for:

- 🔗 Additional integrations
- 🤖 Automation

---

## 🤖 Automation

AWS health events can be used with tools such as:

- 🛠️ **AWS Health Aware**
- ⚡ **Amazon EventBridge**

These tools can help automate:

- 🔔 Notifications
- ⚙️ Actions in response to health events

This can improve:

- ⚡ Response times
- 🛠️ Operational efficiency

---

## 🎯 Use Cases

The AWS Health Dashboard can help users:

- 👀 Monitor AWS service health.
- 🔍 Understand current AWS issues.
- 📜 Review historical service disruptions.
- 👤 Determine whether AWS issues affect their specific resources.
- 🏗️ Plan for high availability.
- 🔔 Automate notifications for health events.
- ⚙️ Automate actions in response to health events.

---

## ⚖️ Key Benefits

- 🏥 Provides visibility into AWS service health and issues.
- 🌎 Shows events affecting all AWS users.
- 👤 Shows events specific to an account's resources.
- 📜 Provides historical information about past issues.
- 🔍 Helps correlate AWS issues with resources and services being used.
- 🏢 Provides benefits for AWS Organizations.
- 🔗 Provides Health API access with a business or enterprise-level support plan.
- 🤖 Supports automation using AWS Health Aware and EventBridge.
- ⚡ Helps improve response times and operational efficiency.
- 🏗️ Supports planning for high availability and operational readiness.

### 🧠 Key Idea

**AWS Health Dashboard = Monitor AWS service health and understand potential impacts**

**Service Health = AWS issues affecting all users**

**Your Account Health = AWS issues affecting your specific resources and services**

**Health API = Enables additional integrations and automation**

**EventBridge = Helps automate notifications and actions for health events**
