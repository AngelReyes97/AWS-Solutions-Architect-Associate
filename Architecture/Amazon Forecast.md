# 🛡️ Amazon Forecast Overview  

## 🧩 Definition
**Amazon Forecast** is a fully managed service that uses **machine learning** to provide accurate forecasts for **time series data sets**.  

**Time series data** consists of data points that are ordered by time and can be used to predict future trends and outcomes.  

---

## ⚙️ Time Series Forecasting Overview  
**Time series forecasting** helps businesses make accurate predictions by analyzing historical data patterns over time.  

- 📉 **Under-forecasting** can lead to:
  - Missed opportunities.
  - Insufficient resources to meet demand.

- 📈 **Over-forecasting** can lead to:
  - Wasted resources.
  - Excess capacity or inventory.

---

## ⚙️ Features and Use Cases  

### 🏢 Business Planning Use Cases
Amazon Forecast supports various planning scenarios, including:

- 📦 **Capacity Planning**
  - Helps forecast future resource requirements.

- 🛒 **Demand and Inventory Planning**
  - Helps predict demand and manage inventory needs.

- 👥 **Workforce Planning**
  - Helps forecast workforce requirements.

Each use case represents a specific **data set domain**.

## 📊 Dataset Types  

Amazon Forecast supports three types of datasets:

### 1. 🎯 Target Time Series
- Essential dataset required for generating forecasts.
- Contains the time series data used to predict future outcomes.

### 2. 🔄 Related Time Series
- Provides additional time-based information related to forecasting.

### 3. 🏷️ Item Metadata
- Contains information about items used during forecasting.

---

## 🛠️ Amazon Forecast Process  
Amazon Forecast simplifies forecasting through a three-step sequence:

1. 📥 **Import Data**
   - Import required datasets into Amazon Forecast.

2. 🧠 **Train Predictors**
   - Train forecasting models using machine learning.

3. 📈 **Generate Forecasts**
   - Create predictions based on trained models.
